## Требования

- Unity 6000.3.11f1

## Инструкция

1. Перейти на сцену `Assets/Scenes/Game.unity`
2. Нажать Play
3. Насладиться

Управление тач скрином сделано как в оригинале:

  Касание к левой части экрана -> движение влево
  
  Касание к правой части экрана -> движение вправо
